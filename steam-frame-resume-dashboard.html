Steam Frame Clean Resume
(No dashboard on resume)

You’re in your relaxing environment of choice. You need to get up and do something, so you press Power to put your Steam Frame to sleep (suspend). When you come back and wake it, the first thing you see is the dashboard.

I don’t want to come back to a menu. I want to be right back in the nice chill environment where I left off.

Steam Frame Clean Resume takes you straight back to your running environment when you wake, with the dashboard closed. It’s especially handy if your controllers aren’t nearby: you don’t have to go find one and turn it on just to close the menu. The Steam button still brings up the dashboard whenever you want it.

Theater mode and floating windows are not affected. If you put the Frame to sleep while playing a game in theater mode, your theater screen and floating windows are still there, ready to go when you resume. It only closes the dashboard. It does not close your game, theater mode or floating windows.

Unofficial installer for keeping the SteamVR dashboard closed on resume. Created with AI assistance

Install

  1. On your Frame, save the accompanying Steam-Frame-Resume-Install.run in Downloads.
  2. Open Konsole, then copy and paste this whole command:
bash ~/Downloads/Steam-Frame-Resume-Install.run

Select Enter on the on-screen keyboard. Wait for Installed. You can close Konsole afterwards. Running this same installer again does not create duplicates.

Never used Desktop or Konsole on Frame?

These steps use the default Frame controller controls. Point and pull the trigger to select. Press the thumbstick inward for the context menu, then use the trigger to choose an item.

  1. Press the controller’s Steam button. In the dashboard dock, select + (Launch Program) → Desktop.
  2. Open the desktop’s application menu at the bottom left. Search for Konsole (with a K) and select it. Use the VR window’s keyboard button to bring up the on-screen keys, selecting them with the trigger.
  3. In this guide, hold the trigger and drag across the command to select the whole line. Release the trigger, press the thumbstick inward over the selection, then select Copy.
  4. Select the dark area inside Konsole with the trigger. Press the thumbstick inward and select Paste. Use the window’s keyboard button, then select Enter on the on-screen keyboard.

Reading on another device? Open this guide and download the installer on your Frame. You can find Chromium, the web browser, in the same desktop application menu. If it offers Install Chromium, select that first and follow its Install button.

Confirm it worked

With your VR environment or game running, press Power to suspend, then wake normally. You return to your running environment with the dashboard closed. If you were playing in theater mode or using floating windows, they remain in place. Afterwards, press Steam: the dashboard should open and stay open until you close it.

What it changes

A small background helper waits for SteamOS’s resume event and sends SteamVR’s built-in dashboard-close request once. It uses no polling or sleep inhibitor. It does not change tracking, boundaries, graphics, game launching, or Steam settings.

Measured idle RAM: about 0.3 MB (0.002% of Frame RAM) for the helper, with no measurable idle CPU use. Linux’s whole-service reading after resume was 4.5 MB (0.028%), including about 4 MB of reclaimable file cache. Measured on SteamOS 0.5.6, 19 October 2026; readings vary.

No administrator password or debugging mode is needed. The installer and helper make no internet requests or uploads. The installer includes the compiled native helper and its readable C source. Python and a compiler are not needed to install or run it. It briefly reads the existing SteamVR log to check for dashboard use, and never sends that log anywhere.

Exactly where it installs

~ means your home folder. Everything persistent is inside it:

  • ~/.local/share/frame-resume-dashboard/: the native helper, C source, uninstaller and ownership marker.
  • ~/.config/systemd/user/frame-resume-dashboard.service: its startup service.
  • ~/.config/systemd/user/default.target.wants/frame-resume-dashboard.service: the link that enables startup.

Setup uses a temporary /tmp/frame-resume-dashboard.* folder and removes it when it finishes. The downloaded installer stays in Downloads. Status messages go to the normal user service journal. No existing Steam configuration is edited, so none needs restoring.

Uninstall

Copy this into Konsole using the same controller steps:

bash ~/.local/share/frame-resume-dashboard/uninstall.sh

Select Enter on the on-screen keyboard. This stops and removes the helper, service and startup link. The usual dashboard-on-resume behaviour returns. The downloaded installer remains as an ordinary, inactive file. You can delete it in the file manager.

Tested with an actual suspend/resume cycle and normal Steam-button access on SteamOS 0.5.6, 19 October 2026.
